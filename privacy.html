Privacy Policy

MoMo AI OS · Last updated November 8, 2026

Who uses MoMo AI OS

MoMo AI OS is a private app with a single user, who is also its developer. It is not offered to the public and has no other users.

What data it accesses

With the user's permission, MoMo AI OS accesses only the user's own Google account (momo.ritch10@gmail.com) through Google APIs:

  • Google Drive, Sheets and Docs: to create, file, rename and read the user's own folders, documents and spreadsheets.
  • Gmail: to read messages the user sends to the app's filing address, save their attachments to Drive, and label processed messages.

How data is used

Data is used only to organize the user's own records for the user. Document text may be sent to Anthropic's Claude API to classify and summarize the document; results are stored back in the user's own Google Drive. Nothing is used for advertising, and no data is sold or shared with anyone else.

Where data is stored

Records stay in the user's Google account. The app runs on the user's own computer, which keeps short-lived working files and activity logs.

Google API Services User Data Policy

MoMo AI OS's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The user can revoke the app's access at any time at myaccount.google.com/permissions.
